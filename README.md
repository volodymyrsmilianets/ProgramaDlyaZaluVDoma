# TRPoint — Розумний Фітнес-Асистент

### Мета (Elevator Pitch)
TRPoint — це веб-додаток для персоналізованих тренувань, який поєднує в собі конструктор вправ та інтелектуального ШІ-коуча. Система не просто відповідає на питання, а аналізує стан користувача (ІМТ, рівень підготовки, водний баланс) та візуалізує техніку виконання вправ за допомогою ШІ-команд.

### Цільова аудиторія
Люди, що тренуються вдома або в залі, яким потрібна швидка консультація щодо техніки вправ та автоматизований підбір програми тренувань.

### Технологічний стек
* **Frontend:** HTML5, CSS3 (Modern UI), JavaScript (Vanilla).
* **AI Integration:** Google Gemini API (Model: 1.5 Flash).
* **Patterns:** Function Calling (модель ініціює виклик графічних вікон інструкцій).

### Інструкція із запуску
1. Завантажте архів з файлами проєкту.
2. Відкрийте файл `index.html` у будь-якому сучасному браузері.
3. Для роботи чату переконайтеся, що у файлі `ai.js` вказано ваш API Key (надається у звіті).
4. Зареєструйтеся в додатку та заповніть профіль для коректної роботи ШІ.
